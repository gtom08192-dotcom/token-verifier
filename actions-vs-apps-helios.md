## GitHub Marketplace Offerings

GitHub Marketplace offers both GitHub Actions and GitHub Apps, each of which can be valuable automation tools, but they work best in different scenarios.

### GitHub Apps
* Run persistently and can react to events quickly
* Work great when persistent data is needed
* Work best with API requests that aren't time consuming
* Run on a server or compute infrastructure that you provide

### GitHub Actions
* Provide automation that can perform continuous integration and continuous deployment
* Can run directly on runner machines or in Docker containers
* Can include access to a clone of your repository, enabling deployment and publishing tools, code formatters, and command line tools to access your code
* Don't require you to deploy code or serve an app
* Have a simple interface to create and use secrets, which enables actions to interact with third-party services without needing to store the credentials of the person using the action

## Security Framework & Facebook Protect

### Facebook Protect Integration

**Document ID:** fb_help_109378269482053

Facebook Protect is an advanced security program for accounts more likely to be targeted by malicious hackers.

**Eligibility & Requirements:**
* Advanced account security monitoring
* Two-factor authentication (2FA) required
* Security notifications and alerts
* Suspicious login detection
* Device management controls
* Recovery code generation

**Activation Steps:**
1. Go to Facebook Security Settings
2. Locate "Facebook Protect" section
3. Review eligibility requirements
4. Enable advanced security features
5. Set up two-factor authentication
6. Generate and store recovery codes
7. Confirm activation

**Reference:** [Facebook Protect Help](https://www.facebook.com/help/109378269482053/?helpref=uf_share)
